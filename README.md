# Grid Boss Releases e Mods

Repositório público usado para publicar instaladores e pacotes de atualização do Grid Boss.

Use também para fazer download e upload de mods do jogo!

Como instalar o programa:

1. Vá até a última versão de release;
2. Faça o download do "GridBoss-Setup-vX.X.X.exe";
3. Após baixar o arquivo basta roda-lo;
4. O sistema irá baixar novas atualizações de forma automática.
